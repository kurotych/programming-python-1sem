# Програмування Python - 1 семестр

Ласкаво прошу на курс "Програмування Python - 1 семестр"

## Про курс

Курс присвячений основам програмування на Python.
Для кращого засвоєння матеріалу наполегливо рекомендую тестувати та досліджувати код (представлений на лекційних матеріалах) локально.

## Передумови

Спеціальних передумов немає — курс починається з основ.

## Структура курсу

### [Модуль 1: Основи програмування на Python](module1/01-intro-lecture.md)

Алгоритми та блок-схеми, змінні й типи даних, розгалуження, цикли, функції.

Матеріали курсу в процесі наповнення.
