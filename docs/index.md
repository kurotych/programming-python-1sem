# Програмування Python - 1 семестр

Ласкаво прошу на курс "Програмування Python - 1 семестр"

## Про курс

Курс присвячений основам програмування на Python.
Для кращого засвоєння матеріалу наполегливо рекомендую тестувати та досліджувати код (представлений на лекційних матеріалах) локально.

## Передумови

Спеціальних передумов немає — курс починається з основ.

## Політика використання ШІ

На протязі першого семестру використання ШІ **заборонено**, оскільки якісне засвоєння основ програмування залишається важливою навичкою.
Якщо ви віддасте мисленнєвий процес штучному інтелекту ви не навчитесь вирішувати складні завдання,
адже для того щоб вирішувати складні завдання спочатку потрібно навчитись вирішувати простіші.
