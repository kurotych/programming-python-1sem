# 28. (П12) Створення власних модулів: модуль для роботи з файлами

## Мета роботи

Навчитися створювати власний модуль: проєктувати його публічні функції, документувати їх, відокремлювати код модуля від коду, що його використовує, оформлювати самоперевірку через `if __name__ == "__main__":`, імпортувати модуль різними формами та повторно використовувати одні й ті самі функції у кількох програмах.

## Хід роботи

Розробіть модуль для роботи з файлами. Назва модуля — `прізвище_files.py`, де прізвище — ваше, латиницею і малими літерами (наприклад, `petrenko_files.py`). Теоретичний матеріал — [лекція 27](27-modules-packages-lecture.md).

Модуль повинен містити такі функції:

1. `list_files(directory)` — повертає список файлів у директорії `directory`.
2. `find_files(directory, substring)` — шукає в директорії файли, у назві яких є переданий підрядок `substring`, і повертає список знайдених.
3. `create_file(path, text)` — приймає два аргументи: шлях до файлу та текст, і створює новий файл із цим текстом.

Вимоги до модуля:

- у кожної функції є docstring з описом параметрів і результату;
- функції модуля нічого не виводять, а повертають результат;
- під час `import` модуль нічого не виконує і не виводить;

Поруч із модулем створіть файл `main.py`, який імпортує ваш модуль і використовує всі три функції на **ваших реальних даних**: виводить список файлів одного з каталогів на вашому компʼютері, шукає в ньому файли за підрядком і створює файл з вашим імʼям, прізвищем і групою.

Покажіть вивід `python3 прізвище_files.py` (самоперевірка) і `python3 main.py`.
